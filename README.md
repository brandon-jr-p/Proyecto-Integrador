# **Proyecto Integrador**

## **1. Preparación de la Escena y Referencias**

Antes de dibujar, es fundamental establecer el "tempo" de la caminata.

- Importar Referencia: Utiliza una imagen que contenga las poses principales: Contacto, Descenso, Pasada y Ascenso.
- Configuración de Capas: En el objeto Grease Pencil, crea al menos dos capas: una para el Boceto (con opacidad baja) y otra para el Lineart/Color final.
- Papel Cebolla (Onion Skinning): Activa esta opción en las propiedades del objeto para ver el dibujo anterior y posterior. Esto es vital para mantener la consistencia del volumen del personaje.

## **2. Bloqueo de Poses Clave (Keyframes)**

No intentes dibujar todo de corrido. Trabaja primero las poses que definen el movimiento:

1. Pose de Contacto (Frame 1): Ambos pies tocan el suelo. Es la extensión máxima de las piernas.
2. Pose de Pasada (Frame intermedio): Una pierna está estirada sosteniendo el peso y la otra está en el aire cruzando hacia adelante.
3. Pose de Contacto Inversa: Igual a la primera, pero con las piernas intercambiadas.

## **3. Definición de la Trayectoria y Arcos**

Para que el gato no parezca que flota, debemos cuidar la altura de la cabeza.

- En la Pose de Pasada, el cuerpo suele estar en su punto más alto.
- En las Poses de Contacto, el cuerpo baja ligeramente.
- Dibuja una línea guía horizontal para asegurar que los pies siempre "pisen" el mismo nivel del suelo.

## **4. Pulido y Color (Workflow de tus capturas)**

Cierre de Trazos: Asegúrate de que las líneas estén cerradas para usar la herramienta Fill (Bote de pintura).
Consistencia de Color: Define una paleta de materiales fija para que el azul del cuerpo y el rosa de las orejas no varíen entre cuadros.
Limpieza: Usa la herramienta de Esculpir (Smooth) para suavizar líneas que hayan quedado temblorosas durante el dibujo a mano alzada.
